## Scope and standard

The release documentation standard is `docs/ddoc-style.md`.
The source Ddoc attached to declarations is authoritative; generated DDox is a
derived publication artifact. Review must distinguish the supported root
import (`import raster;`) from package-private constructors and execution code.

A complete review requires reading **every** supported public declaration and
nontrivial internal function, checking the actual rendered public-only DDox site,
and recording human judgments on semantics and explanations. CI success alone
does not establish that standard.

## Identified and corrected

- `writable_view.d` described its public view as available “from E5.4g.1
  onward.” This was development-history vocabulary rather than useful consumer
  documentation. The module now states the current public/API versus
  package-internal boundary without changing code or declarations.
